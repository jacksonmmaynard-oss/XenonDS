# XenonDS brand assets

The XenonDS identity uses a dual-screen mark, a geometric wordmark, and a
high-contrast technical palette.

## Files

- `logo.png`: stacked XenonDS logo on a transparent background
- `social-preview.png`: 1280 x 640 repository banner

## Colors

| Color | Hex | Role |
| --- | --- | --- |
| Xenon Lime | `#B7FF00` | Primary accent |
| Signal Cyan | `#14C8FF` | Secondary accent |
| Night | `#090B10` | Background |
| Off White | `#F4F7FA` | Primary text |
| Slate | `#8B95A7` | Supporting text |

The logo should retain its original proportions and clear space. The social
preview uses a solid background for consistent rendering across platforms.
