# XenonDS visual identity starter

This is a deliberately editable first pass, not a locked brand system. The SVG
files use simple geometry and live text so they can be refined in Illustrator,
Figma, Affinity Designer, or Inkscape.

## Proposed direction

Concept A, the dual-screen terminal, is the proposed primary mark. It conveys
Nintendo DS emulation without reproducing a console silhouette or an existing
platform logo. The top display contains code lines, while the lower display
contains a small pixel signal. The divided lime and cyan palette represents the
two processors and two screens of the original hardware.

Concept B explores an abstract Xenon core. Concept C combines dual displays
with a central processor and bus traces. Both are included as editable alternates.

## Typography

- Suggested display typeface: Space Grotesk SemiBold
- Suggested interface typeface: Inter
- Current SVG fallback: Segoe UI, Arial, sans-serif

The wordmark remains live text so a final typeface can be selected and outlined
later. Keep `Xenon` in off white and `DS` in Xenon Lime on dark backgrounds.

## Usage

- Keep clear space around the mark equal to one hinge-bar width.
- Do not add an Xbox sphere, Nintendo racetrack, controller, or copyrighted
  platform logo.
- Use the monochrome mark for very small sizes or single-color printing.
- Prefer the full lockup above 320 pixels wide. Use the standalone mark for
  avatars and favicons.
